A Node 22 program that writes one original poem about agency to `/output/entry.txt`: twelve jurors, one room, one word to say — a juror speaks the verdict aloud, and the power to decide goes home with her and has not put her down since.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
